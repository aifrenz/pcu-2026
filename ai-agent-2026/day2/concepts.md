# DAY 2 개념 정리 — 강의 내용 한눈에

강의 슬라이드의 핵심을 글로 정리했습니다. 실습하다 헷갈릴 때 돌아와 보세요.

## 1. 챗봇과 개인 AI 비서는 무엇이 다른가

| | 챗봇 (어제) | 개인 AI 비서 (오늘) |
| --- | --- | --- |
| 시작 | 내가 물어볼 때만 | 정해진 시간 · 사건이 생기면 스스로 |
| 기억 | 이 대화창 안에서만 | 지시문 · 메모리 · 파일로 계속 기억 |
| 손발 | 대화 안의 검색 · 파일 · 코드 | 메신저 · 메일 · 캘린더 · 내 파일까지 |
| 결과 | 화면에 답이 뜬다 | 메신저 · 메일로 결과가 도착한다 |
| 위험 | 틀린 답을 내가 걸러 낸다 | 준 권한만큼 실수의 범위도 커진다 |

**비서 = 에이전트 + 기억 · 예약 · 연결.** 오늘 실습에서 이 세 가지를 하나씩 붙입니다.

## 2. 개인 AI 비서의 유형

| 유형 | 예 | 좋은 점 | 신경 쓸 점 |
| --- | --- | --- | --- |
| 범용 AI 내장형 | Claude · ChatGPT · Gemini의 프로젝트 · 예약 · 커넥터 | 설치 없이 지금 바로 | 그 서비스 안에서만 동작 |
| 셀프호스팅형 | OpenClaw, Hermes Agent | 메신저로 언제든 호출, 내 서버에서 동작 | 서버 · 업데이트 · 키 관리를 내가 |
| 자동화 워크플로 | n8n, Make + AI 노드 | 정해진 흐름을 매일 정확히 | 설정이 많고 API 키가 필요 |

- **OpenClaw:** 많은 스킬을 설치해 쓰는 메신저 비서. ChatGPT 구독 로그인을 공식 지원합니다.
- **Hermes Agent:** 일을 끝낸 뒤 스스로 스킬 파일을 만들어 다음에 다시 쓰는 것이 특징입니다.
- Claude Pro · Max 구독은 서드파티 에이전트에 연결할 수 없습니다. Claude 모델은 API 키로 연결합니다.

## 3. 트리거 세 가지: 시간 · 사건 · 호출

| 트리거 | 언제 | 예 | 도구 |
| --- | --- | --- | --- |
| 시간 (예약) | 정해진 시각 · 주기마다 | 매일 08:00 뉴스 브리핑, 매주 금요일 주간 보고 초안 | n8n Schedule, 범용 AI 예약 기능 |
| 사건 (이벤트) | 무언가 생기면 바로 | 새 메일 도착 → 분류, 폼 제출 → 요약 | n8n Gmail · Form · Webhook 트리거 |
| 호출 (대화) | 내가 말을 걸 때 | 메신저로 "회의 자료 요약해 줘" | OpenClaw · Hermes 메신저 |

시나리오 카드의 1번 칸 '트리거 · 주기'가 이것입니다.

## 4. Workflow + Agent: 뼈대는 고정, 판단만 AI에게

```
트리거 → 자료 가져오기 → [ AI 판단 ] → 형식 맞추기 → 보내기
 (Workflow)  (Workflow)       (Agent)      (Workflow)    (Workflow)
```

| 업무 | 트리거 | AI 판단 (매번 달라지는 것) | 출력 | 사람 확인 |
| --- | --- | --- | --- | --- |
| 주간 업계 브리핑 | 매주 월 08:00 | 내 분야에 중요한 3개 선별 | 메일 | 처음 몇 주 |
| 고객 문의 메일 | 메일 도착 | 유형 분류 · 긴급도 · 답변 초안 | 담당자 메신저 | 답변 발송 전 |
| 회의록 → 할 일 | 파일 업로드 | 결정 · 할 일 · 담당 추출 | 할 일 표 | 배포 전 |
| 지원사업 공고 | 매주 월 · 목 | 우리 회사 지원 가능 여부 | 팀 메신저 | 지원 결정 |
| 설문 응답 정리 | 폼 제출 | 주제별 묶기 · 요약 | 스프레드시트 | 공개 전 |

**가운데 'AI 판단'만 매번 달라집니다. 나머지는 Workflow로 고정하세요.** 판단이 필요 없는 일까지 AI에게 맡기면 느리고, 비싸고, 결과가 들쭉날쭉해집니다.

## 5. 외부 도구와 연결하기

### Tool Calling

AI는 도구를 직접 실행하지 않습니다. **어떤 도구를 어떤 값으로 부를지 적은 요청서(tool_use)**만 쓰고, 실행은 프로그램이 합니다. 결과(tool_result)를 받은 AI가 최종 답을 씁니다. DAY 1 심화 B([`../day1/advanced/B_tool_calling/`](../day1/advanced/B_tool_calling/))에서 직접 돌려 볼 수 있습니다.

### API와 MCP

| | API | MCP |
| --- | --- | --- |
| 무엇 | 프로그램끼리 대화하는 약속 (서비스마다 다름) | AI에 도구를 꽂는 표준 규격 |
| 비유 | 기기마다 다른 충전기 | USB-C 하나로 어디서나 |
| 연결 수 | AI 수 × 도구 수만큼 따로 | 도구를 한 번 MCP 서버로 만들면 MCP를 지원하는 AI 어디서나 |

### 구독과 API 키는 다르다

| | 구독 | API 키 |
| --- | --- | --- |
| 비용 | 월 정액(또는 무료), 한도 안에서 | 쓴 만큼 (토큰 단위) |
| 쓰는 곳 | 그 회사의 웹 · 앱 · 공식 도구 | OpenClaw · Hermes · n8n 등 내가 고른 도구 |
| 오늘 | 기본 실습 전부 | 심화 실습만 |

- Claude Code는 Claude Pro · Max 구독에 포함됩니다. 단, 컴퓨터에 `ANTHROPIC_API_KEY` 환경 변수가 있으면 구독 대신 API로 과금됩니다.
- n8n의 AI Agent 노드는 구독이 아니라 **API 키**로 연결합니다.
- **API 키는 비밀번호입니다.** 지출 상한을 먼저 걸고, 화면 공유 · 스크린샷 · 제출물에 노출하지 마세요.

## 6. 커넥터 권한 화면 읽는 법

| 권한 화면에 나오는 문장 (예) | 판단 | 왜 |
| --- | --- | --- |
| 메일 읽기, 검색 | 허용 | 요약 · 분류에 필요한 최소 권한 |
| 캘린더 일정 보기 | 허용 | 겹치는 일정을 찾는 데 필요 |
| 내 이름으로 메일 보내기 | 주의 | 보내기 전 확인 단계가 있을 때만 |
| 일정 만들기 · 수정 · 삭제 | 주의 | 초안만 만들고 확정은 사람이 |
| 드라이브 모든 파일 삭제 | 거부 | 실습 비서에게 필요 없는 권한 |
| 결제 · 송금 | 거부 | 에이전트에 맡기지 않는다 |

**원칙: 읽기부터 · 필요한 것만 · 테스트 계정으로 · 끝나면 연결 해제.**
