# DAY 2 강의 시연 다시 보기 · 따라 하기

강의에서 강사가 **화면에서 직접 설치해 보여 준 장면**을 그대로 적었습니다. 수업 중에는 보기만 하면 되고, 따라 해 보고 싶다면 집에서 이 순서대로 하세요. 기본 실습 완주에는 필요 없습니다.

| 장면 | 무엇을 | 따라 할 때 필요한 것 | 걸리는 시간 | 파일 |
| --- | --- | --- | --- | --- |
| 1 | 메신저 비서를 직접 깔고 두 비서에게 같은 일 시키기 | 디스코드(무료), 모델 API 키(또는 ChatGPT 구독 · Nous Portal), 설치할 컴퓨터 | 30~60분 | [`1_hermes_openclaw.md`](1_hermes_openclaw.md) |
| 2 | n8n을 띄우고 '주간 AI 뉴스 브리핑' 돌리기 | Node.js, 모델 API 키 | 40~60분 | [`2_n8n_briefing.md`](2_n8n_briefing.md) |

## 시작 전에 꼭

- **Docker는 필요 없습니다.** 두 장면 모두 설치 명령 한 줄이나 데스크톱 앱으로 됩니다.
- **API 키에는 지출 상한을 먼저 겁니다.** 키와 디스코드 봇 토큰은 비밀번호입니다. 화면 공유 · 스크린샷 · 제출물에 넣지 않습니다.
- **개인 메일 · 드라이브 · 회사 계정은 연결하지 않습니다.** 이 장면들은 웹 검색과 붙여 넣은 가상 자료만으로 충분합니다.
- 설치 명령은 버전마다 바뀝니다. 막히면 각 도구의 공식 문서를 기준으로 합니다.

## 강의에서 본 것과 내 결과가 다르면

정상입니다. 모델 · 버전 · 그날의 뉴스에 따라 결과가 달라집니다. 이 파일들의 **'이렇게 나오면 성공'** 칸은 정답이 아니라 **무엇을 확인하면 되는지**를 적은 것입니다.
