# 심화 4 · 미니 에이전트 루프를 코드로 보기

강의에서 말한 **에이전트 루프(계획 → 도구 실행 → 관찰 → 다시 계획)**와 **사람 확인 지점**이 실제로 어떻게 돌아가는지, 150줄짜리 파이썬 파일 하나로 봅니다. **API 키 없이** 돌아갑니다.

```
목표 → [두뇌] 다음에 무엇을 할지 정함 → [프로그램] 도구 실행 → 결과를 두뇌에게 → … → 최종 답
                     (Agent)                    (Workflow)
```

## 실행

Python 3.8 이상이면 됩니다. 설치할 패키지가 없습니다.

```bash
python agent_loop.py          # 보내기 전에 승인을 물어봅니다 (y / N)
python agent_loop.py --no     # 승인 질문에 자동으로 '아니오' (강의 시연에서 쓴 방법)
python agent_loop.py --yes    # 승인 질문에 자동으로 '예'
```

```

[1] 생각: 먼저 일정을 읽어야 무엇이 문제인지 알 수 있다.
```

## 무엇을 보면 되나

| 화면에 보이는 것 | 강의의 개념 | 코드 위치 |
| --- | --- | --- |
| `생각:` | AI가 다음 단계를 스스로 정함 (계획) | `MockBrain.next` |
| `도구 요청서:` | AI는 도구를 직접 실행하지 않고 **요청서**만 씀 (Tool Calling) | `brain.next`가 돌려주는 `tool`, `input` |
| `결과(관찰):` | 실행은 프로그램이 하고, 결과를 다시 AI에게 줌 | `run` 함수의 `fn(**d["input"])` |
| `find_conflicts` | **규칙으로 되는 일은 코드로** (겹침 계산은 AI에게 맡기지 않음) | `find_conflicts` 함수 |
| `⏸ 승인 필요` | **되돌릴 수 없는 일 앞의 사람 확인** (Human-in-the-loop) | `NEEDS_APPROVAL`, `approve` |
| `MAX_STEPS = 8` | **멈추는 장치** — 루프가 끝없이 돌지 않게 | 파일 위쪽 |

## 바꿔 보기 실험

| 실험 | 고칠 곳 | 볼 것 |
| --- | --- | --- |
| 승인 없이 보내게 하면? | `NEEDS_APPROVAL = set()` | 사람 확인 없이 바로 '보냄'. 왜 위험한지 말해 보기 |
| 일정을 바꾸면? | `SCHEDULE`의 화요일 통화를 `"15:40"`으로 | 겹침이 사라지고 메시지 초안 단계를 건너뜀 (루프가 상황에 따라 다른 길로 감) |
| 멈추는 장치를 줄이면? | `MAX_STEPS = 2` | 일을 다 못 끝내고 `[멈춤]` — 비용 · 무한 반복을 막는 장치 |
| 도구를 하나 더하면? | `TOOLS`에 `find_free_time` 추가 | 두뇌가 새 도구를 언제 부를지 정하게 해 보기 |

## 실제 Claude로 돌려 보기 (선택)

두뇌만 진짜 Claude로 바꿉니다. 루프 · 도구 · 승인 코드는 그대로입니다. **API 키(지출 상한 설정)**가 필요하고, 키는 코드에 쓰지 않고 환경 변수로만 넣습니다.

```bash
export ANTHROPIC_API_KEY=...        # Windows PowerShell: $env:ANTHROPIC_API_KEY="..."
python agent_loop.py --real
```

- 모델은 기본값 `claude-sonnet-5-5`이고, `CLAUDE_MODEL` 환경 변수로 바꿀 수 있습니다.
- 모의 두뇌와 달리 매번 생각과 순서가 조금씩 다릅니다. **그게 Agent입니다.** 루프 · 승인 · 멈춤 장치는 똑같이 지켜집니다. **그게 Workflow입니다.**
- 이 경로는 강의 자료 준비 환경에 API 키가 없어 직접 실행해 보지 못했습니다. 오류가 나면 오류 메시지와 함께 알려 주세요.
- 끝나면 터미널을 닫거나 `unset ANTHROPIC_API_KEY` — 이 키가 남아 있으면 Claude Code가 구독 대신 API로 과금됩니다.
