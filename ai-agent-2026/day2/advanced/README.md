# DAY 2 심화 — 강의에서 본 장면을 직접 해 보기

강사가 강의에서 **직접 설치하고 보여 준 장면**을 내 손으로 다시 해 보는 과제입니다. 기본 실습(시나리오 카드 + 1회 실행)을 마친 분이 합니다. 수업 중에 시작하고 마무리는 집에서 해도 됩니다.

> **Docker Desktop은 필요 없습니다.** 모든 과제가 앱이나 명령 한 줄로 설치됩니다.

## 지도

```
              ┌─ 심화 1 · 메신저 비서 (OpenClaw · Hermes) ── 남이 만든 에이전트를 내 서버에
 에이전트 루프 ─┼─ 심화 2 · 2+ · n8n 워크플로 4개 ──────── 정해진 순서(Workflow) 안에 AI 판단(Agent)
 (심화 4)      ├─ 심화 3 · MCP ──────────────────────── 도구를 표준 규격으로 꽂기 · 직접 만들기
              └─ 심화 4 · 미니 에이전트 루프 (150줄) ─── 위 셋의 안쪽에서 도는 것
```

**어디서 시작할까?** 코드가 낯설면 **심화 4**(실행만 하면 루프가 화면에 보임)나 **심화 2**(마우스로 노드 연결)부터, 개발 경험이 있으면 **심화 3의 C**(MCP 서버 직접 만들기)부터 하세요.

## 공통 수칙

- **개인 파일 · 메일 · 회사 계정을 연결하지 않은 상태로** 시작합니다. 모든 과제는 가상 자료로 됩니다.
- OpenClaw · Hermes처럼 셸 · 파일에 닿는 에이전트는 **명령 실행 · 파일 쓰기를 '승인 후 실행'**으로 둡니다. 설정으로 막을 수 없으면 별도 컴퓨터 · 가상 머신에서 씁니다.
- **도구를 줄이는 것이 가장 확실한 권한 관리**입니다. MCP 서버 · n8n 도구 · 비서의 도구 목록에서 필요 없는 것은 뺍니다.
- API 키에는 **지출 상한**을 먼저 겁니다(가장 확실한 방법: 선불 크레딧 소액 충전 + 자동 충전 끄기). 키는 화면에 띄우지 않고, 실습 뒤에는 폐기하거나 한도를 낮춥니다.
- 설치 명령과 메뉴 이름은 버전마다 바뀝니다. 막히면 각 프로젝트의 공식 문서를 기준으로 합니다.
