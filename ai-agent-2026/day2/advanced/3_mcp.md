# 심화 3 · MCP 서버 1개 연결

MCP(Model Context Protocol)는 AI 도구에 **새 도구를 꽂는 표준 규격**입니다. 쓰고 있는 AI 도구(데스크톱 AI 앱 · 코딩 에이전트 · n8n)에 MCP 서버 하나를 붙이고, **AI가 쓸 수 있는 도구 목록이 늘어나는지** 확인합니다.

## 무엇을 연결해 볼까

처음에는 **내 개인 데이터에 닿지 않는 것**부터 고릅니다.

| 연결 대상 | 늘어나는 도구 | 위험도 |
| --- | --- | --- |
| 날짜·시간, 계산 같은 단순 도구 | 현재 시각, 계산 | 낮음 |
| 공개 문서 검색 (예: 라이브러리 공식 문서) | 문서 검색·읽기 | 낮음 |
| 실습용 빈 폴더 하나 (파일 시스템) | 파일 읽기·쓰기 | 중간 — 그 폴더만 허용 |
| 내 메일·드라이브·캘린더 | 읽기·보내기·지우기 | 높음 — 오늘은 하지 않기 |

## 확인할 것

1. 연결 전후로 AI에게 `지금 쓸 수 있는 도구 목록을 보여 줘`라고 물어 비교합니다.
2. 새 도구를 쓰는 요청을 한 번 해 보고, **도구 호출(요청서)** 화면이 보이는지 확인합니다. DAY 1 심화 B에서 본 tool_use와 같은 구조입니다.
3. 권한 화면에서 무엇을 허용하는지(읽기·쓰기·보내기) 읽어 봅니다.

## 수칙

- 출처를 알 수 없는 MCP 서버는 설치하지 않습니다. 공식 저장소나 서비스 회사가 직접 낸 것을 씁니다.
- 파일 시스템 서버는 **실습용 빈 폴더 하나만** 허용합니다.
- 연결 방법은 도구마다 다릅니다. 각 도구 문서의 'MCP' 항목을 따릅니다.
