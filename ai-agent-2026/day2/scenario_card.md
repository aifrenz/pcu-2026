# AI 비서 시나리오 카드 (7칸)

어제 Google Form 5번 '다음에 자동화하고 싶은 부분'에서 출발합니다. **마지막 칸이 가장 중요합니다.** 어디까지 고정하고(Workflow) 어디부터 AI에게 맡길지(Agent) 정하세요.

막막하면 [`examples/scenario_examples.md`](examples/scenario_examples.md)의 완성 카드 7개 중 하나를 골라 그대로 써도 됩니다.

## 빈 카드

복사해서 채우세요.

```
[AI 비서 시나리오 카드]
1. 트리거·주기:
2. 입력:
3. 도구:
4. AI 판단:
5. 출력 채널:
6. 사람 확인 지점:
7. Agent / Workflow:
```

## 칸별로 무엇을 쓰나

| 칸 | 물어볼 것 | 예 |
| --- | --- | --- |
| 1. 트리거·주기 | 언제 시작하나? 시간인가, 사건인가? | 매주 월요일 08:00 / 회의록을 올릴 때 / 새 메일이 오면 |
| 2. 입력 | 무엇을 보고 일하나? | 지난 7일 뉴스 / 붙여 넣은 회의록 / 이번 주 캘린더 |
| 3. 도구 | 무엇을 써야 하나? | 웹 검색 / 캘린더·메일 커넥터 / 문서 저장 |
| 4. AI 판단 | 매번 달라지는 판단은 무엇인가? | 중요한 3개 고르기 / 결정과 미결정 구분 / 겹치는 일정 찾기 |
| 5. 출력 채널 | 어디로, 어떤 모양으로? | 메일 제목 + 3줄 + 링크 / 메신저 표 한 장 |
| 6. 사람 확인 지점 | 무엇 전에 내가 보나? | 다른 사람에게 보내기 전 / 처음 3주 |
| 7. Agent / Workflow | 어디까지 고정, 어디부터 AI? | 선별·요약은 Agent, 주기·형식·전달은 Workflow |

## 4번 'AI 판단'은 구체적으로

'AI 판단'이 '요약'뿐이면 매번 같은 일을 시키는 Workflow와 다를 것이 없습니다. **기준이 들어간 판단**을 쓰세요.

| 약한 AI 판단 | 강한 AI 판단 |
| --- | --- |
| 뉴스 요약 | 내 분야 실무자에게 바로 영향을 주는 3개를 고르고 고른 이유를 한 줄씩 |
| 회의록 정리 | 결정·미결정·할 일을 구분하고, 담당·마감이 없으면 '미정'으로 표시 |
| 일정 알려 주기 | 겹치거나 이동 시간이 30분 미만인 일정을 찾아 경고 |
| 공고 찾기 | 우리 회사 조건으로 지원할 수 있는지 판단하고, 마감 7일 이내는 맨 위로 |

## 어제 Form 5번 답을 카드로 바꾸기

어제 쓴 한 줄에서 칸을 뽑아냅니다.

> "**매주** 회의록을 올리면 **할 일표가 담당자에게** 자동으로 가면 좋겠다. 단 **발송 전에는 내가 확인**"

| 칸 | 뽑아낸 것 |
| --- | --- |
| 1. 트리거·주기 | 회의록을 올릴 때 (매주) |
| 2. 입력 | 회의록 |
| 3. 도구 | 없음 (붙여 넣기) → 나중에 메일 커넥터 |
| 4. AI 판단 | 결정·미결정·할 일 구분, 담당·마감 대조, 없으면 '미정' |
| 5. 출력 채널 | 참석자에게 보낼 메일 초안 + 할 일 표 |
| 6. 사람 확인 지점 | 발송 전 |
| 7. Agent / Workflow | 추출·판단은 Agent, '매번 같은 표 형식·발송'은 Workflow |

어제 5번을 비워 뒀거나 막막하면 이 문장 틀을 채워 보세요.

```
매주 [언제] [무엇을 보고] [어떤 판단을] 해서 [어디로] 보내 주면 좋겠다. 단 [무엇] 전에는 내가 확인한다.
```
