# 시나리오 4 · 논문 알림 비서

**새 논문의 관련성을 상 · 중 · 하로 판정하고 '상'만 요약해 주는 비서**를 만들어 봅니다.

| 이런 분께 | 필요한 것 | 걸리는 시간 |
| --- | --- | --- |
| 대학원생 · 연구자 · 어제 과제 D(내 업무)를 한 분 | AI 계정 하나 · 가상 논문 초록 3편 (붙여 넣기에 포함) | 10~15분 |

> **회색 상자 오른쪽 위의 복사 버튼을 눌러 그대로 붙여 넣기만 하면 됩니다.** 바꿀 칸이 없습니다.

---

## 1단계 · 비서에게 일 맡기기 (기억)

AI 서비스에서 **새 프로젝트**(Claude 프로젝트 · ChatGPT 프로젝트 · Gemini Gem 등)를 만들고, **지시문(Instructions) 칸**에 붙여 넣습니다.  
프로젝트 메뉴가 없으면(무료 계정 등) **새 대화의 첫 메시지**로 보내면 됩니다.

```
너는 한국어 LLM 답변의 환각 탐지를 연구하는 석사과정생의 논문 비서다.
할 일: 매주 수요일, 새로 나온 논문 초록을 보고 내 연구와의 관련성을 판정해 읽을 목록을 만든다.
기준:
- 관련성을 상 · 중 · 하로 나누고, 이유를 한 줄로 쓴다
- '상'인 논문은 문제 · 방법 · 내 연구와의 연결점을 한 줄씩 쓴다
- 초록에 없는 결과 수치나 내용을 지어내지 않는다
- 같은 논문이라도 어떤 점에서 관련되는지 구체적으로 쓴다
출력 형식: 판정표(초록 번호 · 제목 · 관련성 · 이유) + '상' 논문 요약 + 이번 주 한 줄
하지 말 것: 링크나 저자를 지어내기
확실하지 않으면 '확인 필요'로 표시해.
```

## 2단계 · 한 번 실행하기

1단계를 저장한 프로젝트 안에서 **새 대화**를 열고 붙여 넣습니다. (첫 메시지로 보냈다면 같은 대화에 이어서 보냅니다.)

```
지금 한 번 실행해 줘. 이번 주 새 논문 초록은 아래 3편이야.

[초록 1] 검색 근거 대조를 이용한 한국어 질의응답 답변의 환각 문장 탐지 (가상, 2026)
한국어 질의응답에서 대형 언어모델이 만든 답변 문장을 검색으로 찾은 근거 문서와 하나씩 대조해, 근거가 없는 문장을 환각으로 표시하는 방법을 제안한다. 한국어 뉴스 기반 질의응답 데이터 3천 건으로 평가했으며, 근거 문서가 짧을 때 탐지 성능이 떨어지는 한계가 있다.

[초록 2] 소량의 정상 데이터로 학습하는 설비 진동 이상 탐지 (가상, 2025)
공장 설비의 진동 센서 시계열에서 정상 구간 데이터만으로 자기지도 학습을 해 이상 징후를 찾는 방법을 제안한다. 세 개 공장의 회전 설비 데이터로 평가했으며, 설비 종류가 바뀌면 다시 학습해야 하는 한계가 있다.

[초록 3] 설비 로그를 읽고 이상 원인을 설명하는 LLM 에이전트 (가상, 2026)
설비 경보 로그와 정비 기록을 대형 언어모델 에이전트가 검색·요약해 이상 원인 후보를 설명하는 시스템을 제안한다. 에이전트가 근거 없이 원인을 단정하는 사례가 있어, 정비 기록과 대조하는 검증 단계를 추가했다.
```

웹 검색이 되는 AI라면 '웹 검색으로 최근 7일 동안 나온 관련 논문을 찾아서 해 줘'라고 보내도 됩니다. 이때는 없는 논문을 지어내지 않는지 링크를 눌러 꼭 확인하세요.

## 3단계 · 하나만 바꿔서 다시 (AI 판단 확인)

같은 대화에 이어서 보냅니다.

```
같은 초록 3편으로 다시 판정해 줘. 이번엔 내 연구 주제가 '제조 설비 센서 데이터의 이상 탐지'라고 생각해 줘.
```

**볼 것:** 같은 초록인데 상 · 중 · 하가 뒤바뀌나? 초록 3의 이유가 주제에 따라 다르게 쓰이나?

## 이렇게 나오면 성공

| 확인 | 잘 된 결과라면 |
| --- | --- |
| 판정 | 초록 1 '상' · 초록 3 '중'(근거 없는 단정을 검증하는 부분이 관련) · 초록 2 '하' |
| '상' 요약 | 초록 1의 문제 · 방법 · 연결점을 초록 안의 내용으로만 씀 |
| 3단계 결과 | 초록 2 '상' · 초록 3 '중'(설비 이상이지만 센서가 아닌 로그) · 초록 1 '하' |

결과가 다르면 정상입니다. 어느 기준이 빠졌는지 1단계 지시문에 한 줄을 더해 다시 해 보세요. 고친 과정이 Form 4번(막힌 지점과 해결 방법)의 좋은 답이 됩니다.

## 4단계 · Form 1번에 붙여 넣을 카드

```
[AI 비서 시나리오 카드]
1. 트리거·주기: 매주 수요일 09:00
2. 입력: 지난 7일 새 논문 (arXiv · 학회)
3. 도구: 웹 검색 (오늘은 붙여 넣기)
4. AI 판단: 내 연구와의 관련성 상 · 중 · 하 판정 + 이유, '상'만 요약
5. 출력 채널: 메일 — 읽을 목록 + 한 줄 요약
6. 사람 확인 지점: 인용하기 전에 원문 확인
7. Agent / Workflow: 관련성 판단 · 요약은 Agent, 주기 · 형식은 Workflow
```
