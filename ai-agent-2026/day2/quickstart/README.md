<details><summary><b>모든 시나리오는 같은 4단계</b> — 지시문 저장 → 실행 → 하나만 바꿔 다시 → 제출</summary>

| 단계 | 하는 일 | 비서의 무엇을 보나 |
| --- | --- | --- |
| 1 | 지시문을 프로젝트에 저장 (못 찾으면 첫 메시지로) | **기억** — 매번 다시 설명하지 않아도 됨 |
| 2 | 실행 메시지 붙여 넣기 | 지시문의 기준대로 판단하나 |
| 3 | 조건 하나만 바꿔 다시 | **AI 판단** — 입력이 바뀌면 결과도 바뀌나 |
| 4 | Form 4문항 제출 | 카드는 내일 DAY 3의 설계도 |

</details>

<details><summary><b>메뉴 찾기</b> — 지시문을 저장하는 곳, 3분 안에 못 찾으면 첫 메시지로</summary>

메뉴 이름은 서비스 업데이트로 바뀔 수 있습니다. **3분 안에 못 찾으면 지시문을 새 대화의 첫 메시지로 보내세요.** 그래도 완주입니다.

| 서비스 | 지시문을 저장하는 곳 |
| --- | --- |
| Claude | 왼쪽 메뉴 **프로젝트** → 새 프로젝트 → 프로젝트 화면의 **지시문(Instructions)** |
| ChatGPT | 왼쪽 메뉴 **프로젝트** → 새 프로젝트 → 프로젝트 설정의 **지침** |
| Gemini | 왼쪽 메뉴 **Gem** → 새 Gem 만들기 → **지침**. 2단계부터는 그 Gem과의 대화에서 보냅니다 |

</details>

## 꼭 지킬 것

- 들어 있는 자료는 모두 **가상**입니다. 내 자료로 바꿀 때는 이름 · 연락처 · 금액을 지웁니다.
- 비서가 메일을 보내거나 일정을 바꾸게 하지 않습니다. **초안까지만, 보내는 것은 내가.**
- 웹 검색 결과의 링크는 직접 눌러 확인합니다.
- 막히면 3분 넘게 혼자 고민하지 말고 손을 드세요.
