## 모든 시나리오는 같은 4단계

| 단계 | 하는 일 | 비서의 무엇을 보나 |
| --- | --- | --- |
| 1 | 지시문을 프로젝트에 저장 (없으면 첫 메시지로) | **기억** — 매번 다시 설명하지 않아도 됨 |
| 2 | 실행 메시지 붙여 넣기 | 지시문의 기준대로 판단하나 |
| 3 | 조건 하나만 바꿔 다시 | **AI 판단** — 입력 · 조건이 바뀌면 결과도 바뀌나 |
| 4 | 카드를 Form 1번에 붙여 넣기 | 내일 DAY 3의 설계도 |

예약 기능이 있는 플랜이라면 각 파일 끝의 **예약 걸기** 문장도 보내 봅니다(**예약**). 없으면 건너뛰어도 완주입니다.

## 완주 기준

1~3단계를 해 보고, 4단계 카드와 2단계 결과를 [Google Form](../worksheets/form_questions.md)에 내면 완주입니다.

## 꼭 지킬 것

- 들어 있는 자료는 모두 **가상**입니다. 내 자료로 바꿀 때는 이름 · 연락처 · 금액을 지웁니다.
- 비서가 메일을 보내거나 일정을 바꾸게 하지 않습니다. **초안까지만, 보내는 것은 내가.**
- 웹 검색 결과의 링크는 직접 눌러 확인합니다.
