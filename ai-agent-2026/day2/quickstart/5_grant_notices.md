# 시나리오 5 · 지원사업 공고 비서

**공고 목록을 보고 '우리 회사가 지원할 수 있는지' 판정해 주는 비서**를 만들어 봅니다.

| 이런 분께 | 필요한 것 | 걸리는 시간 |
| --- | --- | --- |
| 회사에서 사업 · 기획을 맡은 분 · 어제 과제 D(내 업무)를 한 분 | AI 계정 하나 · 가상 공고 5개 (붙여 넣기에 포함) | 10~15분 |

> **회색 상자 오른쪽 위의 복사 버튼을 눌러 그대로 붙여 넣기만 하면 됩니다.** 바꿀 칸이 없습니다.

---

## 1단계 · 비서에게 일 맡기기 (기억)

AI 서비스에서 **새 프로젝트**(Claude 프로젝트 · ChatGPT 프로젝트 · Gemini Gem 등)를 만들고, **지시문(Instructions) 칸**에 붙여 넣습니다.  
프로젝트 메뉴가 없으면(무료 계정 등) **새 대화의 첫 메시지**로 보내면 됩니다.

```
너는 대전 소재 직원 30명 소프트웨어 기업의 지원사업 담당 비서다.
할 일: 월요일 · 목요일마다 AI · SW 분야 지원사업 공고를 보고 우리 회사가 지원할 수 있는지 판정한다.
기준:
- 지원 대상 조건(지역 · 업종 · 업력 · 단독 지원 가능 여부)을 우리 회사와 하나씩 대조한다
- 지원할 수 없는 공고는 빼고, 뺀 이유를 한 줄로 남긴다
- 단독으로는 안 되지만 조건을 갖추면 가능한 공고는 '조건부'로 따로 표시한다
- 마감이 지난 공고는 빼고, 마감이 7일 이내인 공고는 맨 위에 '마감 임박'으로 표시한다
출력 형식: 지원 가능 표(사업명 · 주관 · 지원 규모 · 마감일 · 판단 이유) + 조건부 + 제외한 공고와 이유
하지 말 것: 신청서 제출, 공고에 없는 지원 규모 쓰기
확실하지 않으면 '확인 필요'로 표시해.
```

## 2단계 · 한 번 실행하기

1단계를 저장한 프로젝트 안에서 **새 대화**를 열고 붙여 넣습니다. (첫 메시지로 보냈다면 같은 대화에 이어서 보냅니다.)

```
지금 한 번 실행해 줘. 오늘은 10월 15일이야. 이번에 모은 공고는 아래와 같아.

[지원사업 공고 목록] (모두 가상의 공고입니다)

1. 2026 지역 AI 솔루션 실증 지원사업
   주관: 한빛정보산업진흥원 / 대상: 대전·세종·충남 소재 중소 SW 기업 / 규모: 과제당 최대 2억 원 / 마감: 10월 20일

2. 수도권 AI 스타트업 성장 바우처
   주관: 미래창업재단 / 대상: 서울·경기 소재 창업 3년 이내 기업 / 규모: 최대 5천만 원 / 마감: 10월 31일

3. 공공 데이터 활용 서비스 개발 공모
   주관: 데이터누리원 / 대상: 전국 중소기업 / 규모: 최대 1억 원 / 마감: 11월 14일

4. 제조 AI 전환 컨설팅 지원
   주관: 스마트제조혁신센터 / 대상: 제조업 기업(SW 기업은 컨소시엄 참여만 가능) / 규모: 최대 3천만 원 / 마감: 11월 7일

5. 2026 하반기 SW 품질 인증 비용 지원
   주관: 소프트웨어품질협회 / 대상: 전국 SW 기업 / 규모: 인증 비용 70% / 마감: 10월 10일
```

## 3단계 · 하나만 바꿔서 다시 (AI 판단 확인)

같은 대화에 이어서 보냅니다.

```
같은 공고로 다시 판정해 줘. 이번엔 우리 회사가 '서울 소재, 창업 2년 차, 직원 8명 AI 스타트업'이라고 생각해 줘.
```

**볼 것:** 회사 조건만 바꿨는데 가능한 공고와 제외한 공고가 뒤바뀌나?

## 이렇게 나오면 성공

| 확인 | 잘 된 결과라면 |
| --- | --- |
| 맨 위 | 1번 — 마감 임박(10/20), 지원 가능 |
| 지원 가능 | 3번 (전국 중소기업) |
| 조건부 | 4번 — 단독 지원 불가, 제조 기업과 컨소시엄이면 가능 |
| 제외 | 2번 지역 조건(서울 · 경기), 5번 마감 지남(10/10) |
| 3단계 결과 | 1번은 지역 조건으로 제외, 2번이 지원 가능으로 바뀜 |

결과가 다르면 정상입니다. 어느 기준이 빠졌는지 1단계 지시문에 한 줄을 더해 다시 해 보세요. 고친 과정이 Form 4번(막힌 지점과 해결 방법)의 좋은 답이 됩니다.

---

## 4단계 · Form 1번에 붙여 넣을 카드

```
[AI 비서 시나리오 카드]
1. 트리거·주기: 매주 월요일 · 목요일 09:00
2. 입력: 정부 · 공공기관 새 공고
3. 도구: 웹 검색 (오늘은 붙여 넣기)
4. AI 판단: 우리 회사 조건으로 지원 가능 · 조건부 · 제외 판정, 마감 임박 표시
5. 출력 채널: 팀 메신저 — 표 한 장
6. 사람 확인 지점: 지원 여부 결정은 팀장
7. Agent / Workflow: 자격 판단은 Agent, 주기 · 표 형식 · 전달은 Workflow
```

## (가능한 플랜만) 예약 걸기

예약 기능이 있는 서비스라면 같은 대화에 보냅니다. 없으면 건너뛰어도 완주입니다.

```
이 작업을 매주 월요일과 목요일 오전 9시에 실행하도록 예약해 줘. 그때는 웹 검색으로 정부 · 공공기관 공식 사이트의 새 공고를 찾고, 공고 링크를 붙여 줘.
```

## 내 것으로 바꿔 보고 싶다면

첫 줄의 회사 소개를 우리 회사의 공개 정보(지역 · 업종 · 규모 · 업력)로 바꿉니다. 매출 · 내부 사정은 넣지 않습니다.
