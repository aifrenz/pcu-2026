# 처음 하는 분 안내 (3분)

AI 채팅에서 질문만 해 봤다면 이 페이지부터 보세요. 아래 **▶ 줄의 한 줄 요약만 훑어봐도** 오늘 할 일의 흐름이 잡힙니다. 더 알고 싶은 줄은 **눌러서 펼치고**, 다시 누르면 접힙니다.

<details><summary>▶ <b>이렇게 생긴 줄을 눌러 보세요</b> — 눌러서 펼치고, 다시 눌러서 접습니다</summary>

펼쳐졌습니다. 이 페이지와 실습 자료의 자세한 설명 · 정답 · 긴 결과는 모두 이렇게 접혀 있습니다.

</details>

## 한눈에 보기

<details><summary>▶ <b>1. 화면 두 개 쓰기</b> — 왼쪽은 이 자료, 오른쪽은 AI 창</summary>

- **왼쪽에는 이 자료(GitHub), 오른쪽에는 AI 창**(Claude · ChatGPT · Gemini 중 하나)을 띄웁니다.
- 링크는 **Ctrl+클릭**(맥은 **⌘+클릭**)으로 열면 새 탭에서 열리고, 지금 화면이 그대로 남습니다.
- 길을 잃으면 브라우저의 **뒤로(←)** 를 누르면 됩니다.
- 수업 중에는 **이 웹 화면에서** 합니다. ZIP을 받아 메모장으로 열면 기호(```, |, **)가 그대로 보여 더 어렵습니다.

</details>

<details><summary>▶ <b>2. 복사하고 붙여 넣기</b> — 회색 상자의 복사 단추 → AI 입력창에 Ctrl+V → 보내기</summary>

1. 회색 상자 위에 **마우스를 올리면** 오른쪽 위에 **복사 단추(네모 두 개)** 가 나타납니다.
2. 누르면 단추가 **✓**로 바뀝니다. 복사된 것입니다.
3. AI 창의 **입력창을 한 번 클릭**하고 **Ctrl+V**(맥은 **⌘+V**)를 누릅니다.
4. 입력창 오른쪽의 **보내기 단추**(화살표)를 누르거나 Enter를 누릅니다.

```
이 상자로 연습해 보세요. 복사해서 AI에 붙여 넣으면 됩니다. 안녕하세요, 오늘 실습을 시작합니다.
```

상자 안의 긴 글을 다 읽지 않아도 됩니다. 통째로 복사해 붙여 넣는 것이 오늘의 방법입니다.

</details>

<details><summary>▶ <b>3. 오늘 나오는 말 다섯 개</b> — 지시문 · 프로젝트 · 새 대화 · Form · 카드</summary>

| 말 | 뜻 |
| --- | --- |
| **지시문** (ChatGPT · Gemini에서는 '지침') | AI에게 미리 주는 **업무 설명서**. 한 번 넣어 두면 매번 다시 설명하지 않아도 됩니다 |
| **프로젝트** (Gemini에서는 'Gem') | 지시문을 **저장해 두는 방**. 그 방 안에서 여는 대화는 모두 지시문을 기억합니다 |
| **새 대화** | 입력창이 비어 있는 새 채팅. 프로젝트 **밖**의 새 대화는 지시문을 모릅니다 |
| **Form** | 구글 설문지. 오늘 결과를 내는 곳입니다 |
| **카드** | 내 비서 설계 메모 7줄. 시나리오 파일에 완성본이 있어서 복사만 하면 됩니다 |

</details>

<a id="프로젝트-만들기"></a>

<details><summary>▶ <b>4. 프로젝트 만들기</b> — 새 프로젝트(Gemini는 Gem) → 지시문 칸에 붙여 넣고 저장</summary>

메뉴 이름은 서비스 업데이트로 조금 다를 수 있습니다. **3분 안에 못 찾으면 5번 '프로젝트 메뉴가 없을 때'로 하세요.** 그래도 완주입니다.

**Claude**

1. 왼쪽 메뉴에서 **프로젝트** → **새 프로젝트**(또는 **+**)를 누르고 이름을 씁니다 (예: 회의록 비서).
2. 프로젝트 화면 오른쪽의 **지시문(Instructions)** 을 누르고, 시나리오의 1단계 상자를 붙여 넣고 **저장**합니다.
3. 프로젝트 화면 **가운데 입력창**에 2단계 상자를 붙여 넣습니다. 이것이 '프로젝트 안의 새 대화'입니다.

**ChatGPT**

1. 왼쪽 메뉴에서 **프로젝트** → **새 프로젝트**를 누르고 이름을 씁니다.
2. 프로젝트 화면의 설정(⋯ 또는 톱니)에서 **지침**을 찾아 1단계 상자를 붙여 넣고 **저장**합니다.
3. 프로젝트 화면의 입력창에 2단계 상자를 붙여 넣습니다.

**Gemini**

1. 왼쪽 메뉴에서 **Gem** → **새 Gem 만들기**를 누릅니다.
2. 이름을 쓰고 **지침** 칸에 1단계 상자를 붙여 넣은 뒤 **저장**합니다.
3. 만든 Gem을 눌러 열고, 그 대화창에 2단계 상자를 붙여 넣습니다.

</details>

<details><summary>▶ <b>5. 프로젝트 메뉴가 없을 때</b> — 지시문을 첫 메시지로 보내고, 끝까지 같은 대화에서</summary>

무료 플랜이거나 메뉴를 3분 안에 못 찾았다면:

1. **새 대화**를 열고 1단계 상자(지시문)를 **첫 메시지**로 보냅니다. AI가 '알겠습니다'처럼 답하면 정상입니다.
2. 그다음 단계도 모두 **같은 대화에 이어서** 보냅니다. 새 대화를 열면 지시문을 잊어버립니다.

</details>

<details><summary>▶ <b>6. 새 대화? 같은 대화?</b> — 프로젝트를 만들었으면 3단계는 프로젝트 안 새 대화, 아니면 끝까지 같은 대화</summary>

**프로젝트 안에서 새 대화를 여는 법:** 왼쪽 메뉴에서 **내 프로젝트 이름**을 눌러 프로젝트 첫 화면으로 돌아간 뒤, 가운데 입력창에 붙여 넣습니다. (Gemini는 왼쪽의 **내 Gem**을 다시 누릅니다.)

| 나는 | 처음 붙여 넣는 곳 | 다음 단계 |
| --- | --- | --- |
| 프로젝트를 만들었다 | 2단계: 프로젝트 안의 입력창 | 3단계: 프로젝트 안에서 **새 대화** (기억을 확인하는 순간) |
| 첫 메시지로 보냈다 | 2단계: **같은 대화**에 이어서 | 3단계: **같은 대화**에 이어서 |
| 시나리오 0(AI가 물어보며 지시문 만들기)을 한다 | 1단계: 프로젝트 **밖에서** 새 대화 (왼쪽 맨 위 '새 채팅') | 3단계: 새 프로젝트를 하나 더 (못 만들면 새 대화의 첫 메시지로) |

</details>

<details><summary>▶ <b>7. AI 답을 기다릴 때</b> — 10초~1분, 예시와 표현이 달라도 정상</summary>

- 답이 나오기까지 10초~1분쯤 걸립니다. 기다리는 동안 다른 것을 누르지 않습니다.
- 자료에 있는 예시와 **표현이 달라도 정상**입니다. 같은 질문도 할 때마다 조금씩 다르게 답합니다.

</details>

<details><summary>▶ <b>8. 고쳐 쓰는 곳</b> — GitHub 화면은 고칠 수 없으니 Form 칸이나 메모장에서</summary>

GitHub 화면의 글은 **고칠 수 없습니다.** 고쳐 쓸 것은 복사해서 **Form 칸이나 메모장**에 붙여 넣은 뒤 그 안에서 고칩니다.

</details>

<details><summary>▶ <b>9. 제출하기</b> — Form 4문항, 마지막에 '제출' 버튼까지</summary>

- **제출 링크: https://forms.gle/49KjeRbGa6JtS7Lr9**
- 문항 4개에 무엇을 넣는지는 각 시나리오 파일의 **4단계**에 표로 정리되어 있습니다.
- AI 답을 통째로 복사하려면 답 아래의 **복사 아이콘(네모 두 개)** 을 누릅니다.
- 마지막에 Form 아래쪽 **제출** 버튼까지 눌러야 끝납니다.

</details>
