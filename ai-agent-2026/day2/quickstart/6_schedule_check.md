# 시나리오 6 · 다음 주 일정 점검 비서

**다음 주 일정을 보고 겹침 · 빠듯한 이동 · 준비가 필요한 일을 미리 알려 주는 비서**를 만들어 봅니다.

| 이런 분께 | 필요한 것 | 걸리는 시간 |
| --- | --- | --- |
| 일정이 많은 분 · 직장과 학업을 병행하는 분 | AI 계정 하나 · 가상 일정표 (붙여 넣기에 포함) | 10~15분 |

> **회색 상자 오른쪽 위의 복사 버튼을 눌러 그대로 붙여 넣기만 하면 됩니다.** 바꿀 칸이 없습니다.

---

## 1단계 · 비서에게 일 맡기기 (기억)

AI 서비스에서 **새 프로젝트**(Claude 프로젝트 · ChatGPT 프로젝트 · Gemini Gem 등)를 만들고, **지시문(Instructions) 칸**에 붙여 넣습니다.  
프로젝트 메뉴가 없으면(무료 계정 등) **새 대화의 첫 메시지**로 보내면 됩니다.

```
너는 직장과 대학원을 병행하는 사람의 일정 비서다.
할 일: 매주 일요일 저녁, 다음 주 일정을 보고 문제가 될 만한 것을 미리 알려 준다.
기준:
- 시간이 겹치는 일정을 모두 찾는다
- 장소가 다른 일정 사이 간격이 30분 미만이면 경고한다
- 발표 · 시험 · 출장처럼 준비가 필요한 일정은 준비할 것을 한 줄씩 제안한다
- 일정표에 없는 일정을 지어내지 않는다
출력 형식: 경고(최대 3개, 중요한 순서) + 준비할 것 + 요일별 한 줄 요약
하지 말 것: 일정을 직접 바꾸거나 지우기, 다른 사람에게 연락하기
확실하지 않으면 먼저 나에게 물어봐.
```

## 2단계 · 한 번 실행하기

1단계를 저장한 프로젝트 안에서 **새 대화**를 열고 붙여 넣습니다. (첫 메시지로 보냈다면 같은 대화에 이어서 보냅니다.)

```
지금 한 번 실행해 줘. 다음 주 일정은 아래와 같아.

[다음 주 일정] 2026년 10월 19일(월) ~ 10월 23일(금)

10/19(월) 09:30–10:30 주간 팀 회의 (본사 5층)
10/19(월) 19:00–21:30 대학원 수업 '데이터마이닝' (배재대 공학관)
10/20(화) 14:00–15:30 협력사 미팅 (둔산동 협력사 사무실)
10/20(화) 15:00–15:30 고객 화상 통화 (온라인)
10/21(수) 16:30–18:40 외부 세미나 참석 (유성구 연구단지 컨벤션홀)
10/21(수) 19:00–21:00 스터디 모임 (서구 카페)
10/22(목) 10:00–11:00 분기 실적 발표 — 내가 발표자 (본사 대회의실)
10/23(금) 08:00–18:00 서울 출장 (KTX 대전역 07:10 출발)
```

## 3단계 · 하나만 바꿔서 다시 (AI 판단 확인)

같은 대화에 이어서 보냅니다.

```
화요일 협력사 미팅이 14:00–14:50으로 줄었어. 다시 점검해 줘.
```

**볼 것:** 겹침 경고가 사라지거나 '이동 시간 빠듯'으로 바뀌나? (둔산동 → 온라인 통화라 이동이 필요 없는지도 판단하나?)

## 이렇게 나오면 성공

| 확인 | 잘 된 결과라면 |
| --- | --- |
| 경고 | 화요일 15:00 협력사 미팅과 고객 통화가 겹침 · 수요일 18:40 유성 → 19:00 서구 이동 20분 |
| 준비할 것 | 목요일 분기 실적 발표 자료 · 금요일 07:10 KTX라 목요일 밤 출장 준비 |
| 3단계 결과 | 화요일 겹침이 사라지고, 수요일 이동 경고가 맨 위로 |

결과가 다르면 정상입니다. 어느 기준이 빠졌는지 1단계 지시문에 한 줄을 더해 다시 해 보세요. 고친 과정이 Form 4번(막힌 지점과 해결 방법)의 좋은 답이 됩니다.

---

## 4단계 · Form 1번에 붙여 넣을 카드

```
[AI 비서 시나리오 카드]
1. 트리거·주기: 매주 일요일 20:00
2. 입력: 다음 주 캘린더 일정
3. 도구: 캘린더 커넥터 (오늘은 붙여 넣기)
4. AI 판단: 겹치는 일정, 이동 30분 미만, 준비가 필요한 일정 찾기
5. 출력 채널: 메신저 — 경고 3줄 + 요일별 한 줄
6. 사람 확인 지점: 일정 변경 · 취소는 내가 직접
7. Agent / Workflow: 충돌 · 준비 판단은 Agent, 주기 · 형식은 Workflow
```

## (가능한 플랜만) 예약 걸기

예약 기능이 있는 서비스라면 같은 대화에 보냅니다. 없으면 건너뛰어도 완주입니다.

```
이 작업을 매주 일요일 오후 8시에 실행하도록 예약해 줘. 캘린더가 연결되어 있으면 다음 주 일정을 직접 읽고, 일정은 절대 바꾸지 마.
```

## 내 것으로 바꿔 보고 싶다면

첫 줄을 내 상황으로 바꾸고, 일정표는 내 일정을 장소 · 시간만 남겨 적습니다. 함께하는 사람 이름은 빼도 됩니다.
