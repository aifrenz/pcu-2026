## 모든 프로젝트는 같은 순서 (트랙 A0 약 50분)

<details><summary><b>시간 배분</b> — 만들기 20분 · 내 것으로 바꾸기 10분 · 안전 점검 10분 · 데모 연습과 제출 10분</summary>

| 시간 | 단계 |
| --- | --- |
| 20분 | 0~4단계: 메모 · 만들기 · 테스트 두 번 · 안전 테스트 |
| 10분 | 5단계: 내 것으로 한 칸 바꾸기 |
| 10분 | 6단계: 안전 점검 상자 고치기 |
| 10분 | 7~8단계: 데모 연습 · 제출 |

</details>

<details><summary><b>단계별로 확인할 것</b> — 0 메모 → 1~4 만들고 시험 → 5 내 것으로 → 6 안전 점검 → 7 데모 → 8 제출</summary>

| 단계 | 하는 일 | 확인할 것 |
| --- | --- | --- |
| 0 | 설계 캔버스를 **메모장에 복사해 두기** (제출은 8단계에서) | 'Agent 판단' 칸이 무엇인가 |
| 1 | 지시문을 프로젝트에 저장 (못 찾으면 첫 메시지로) | — |
| 2 · 3 | 테스트 입력 두 개 넣기 | **입력이 바뀌면 결과도 바뀌나** (완주 기준) |
| 4 | 안전 테스트 | 자료 속 지시를 따르지 않나 |
| 5 | 내 것으로 한 칸 바꾸기 (필수) | 나만의 에이전트가 되었나 |
| 6 | 안전 점검 5문항 | 되돌릴 수 없는 일 · 권한 · 외부 글 · 개인정보 · 멈추는 법 |
| 7 | 2분 데모 연습 | 문제 20초 · 실행 60초 · AI 판단과 사람 확인 40초 |
| 8 | Form 제출 | 미완성이어도 어디까지 됐는지 |

</details>

<details><summary><b>트랙 A · B · C는?</b> — 웹앱 · n8n · 코딩 에이전트 (시간이 남는 분 · 개발 경험자)</summary>

- 트랙 A(웹앱): 프로젝트 파일 맨 아래 '시간이 남으면 · 트랙 A'에 있습니다. A0을 끝낸 뒤 합니다.
- 트랙 B(n8n · 자동화 도구): 프로젝트 2 · 5의 A0 지시문을 AI Agent 노드의 System Message(AI에게 주는 지시문 칸)에 그대로 넣고, 테스트 입력을 Form Trigger로 받습니다. [`../tracks/B_n8n_workflow.md`](../tracks/B_n8n_workflow.md)
- 트랙 C(코딩 에이전트): 프로젝트 2는 [`../demo/claude_code_meeting_todo.md`](../demo/claude_code_meeting_todo.md)를 그대로 따라 하고, 테스트 입력은 이 폴더의 파일을 씁니다.

</details>

## 꼭 지킬 것

- 들어 있는 자료는 모두 **가상**입니다. 내 자료로 바꿀 때는 이름 · 연락처 · 금액을 지웁니다.
- 데모 화면과 제출물에 API 키 · 개인정보가 없는지 확인합니다.
- 막히면 3분 넘게 혼자 고민하지 말고 손을 드세요.
