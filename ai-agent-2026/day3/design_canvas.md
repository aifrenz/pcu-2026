# 설계 캔버스 (5칸)

어제 시나리오 카드 7칸을 5칸으로 줄입니다. 옮겨 적으면 됩니다. **'Agent 판단' 칸이 비어 있으면 제작에 들어가지 않습니다.**

막막하면 [`examples/project_examples.md`](examples/project_examples.md)의 완성 캔버스 6개 중 하나를 골라 그대로 써도 됩니다. 내 일로 만들고 싶다면 [DAY 2 시나리오 0의 도우미](../day2/quickstart/0_prompt_builder.md#day-3에서-다시-쓰려면)로 **AI가 질문하며 캔버스를 채우게** 할 수 있습니다.

## 빈 캔버스

```
[설계 캔버스]
에이전트 이름:
1. 입력 (사용자가 넣는 것):
2. Agent 판단 (AI가 정하는 것):
3. 도구 (AI가 쓰는 것):
4. 결과 (사용자가 받는 것):
5. 사람 확인 지점 (사람이 승인할 것):
테스트 입력 ①:
테스트 입력 ②:
```

## 어제 카드에서 옮기기

| 어제 카드 (7칸) | 오늘 캔버스 (5칸) |
| --- | --- |
| 1. 트리거·주기 | (오늘은 빼도 됨 — 버튼을 누를 때 실행) |
| 2. 입력 | 1. 입력 |
| 3. 도구 | 3. 도구 |
| 4. AI 판단 | 2. Agent 판단 |
| 5. 출력 채널 | 4. 결과 |
| 6. 사람 확인 지점 | 5. 사람 확인 지점 |
| 7. Agent / Workflow | (판단 칸을 정하는 데 썼으니 오늘은 빼도 됨) |

## 테스트 입력 두 개를 미리 정하세요

완주 기준은 **입력이 바뀌면 결과도 바뀌는 것**입니다. 입력 두 개를 미리 정해 두면 만들자마자 확인할 수 있습니다.

| 좋은 테스트 입력 짝 | 왜 좋은가 |
| --- | --- |
| 관심 분야 '공공 행정' / '반도체 연구' | 같은 뉴스에서 다른 3개를 골라야 함 |
| 회의록 A / 회의록 B | 결정·미정 항목이 달라야 함 |
| 예산 120만 원 · 배터리 중시 / 180만 원 · 화면 중시 | 추천이 달라야 함 |

나쁜 짝: '공공 행정' / '공공 행정 업무' — 너무 비슷해서 결과가 같아도 판단이 있는지 알 수 없습니다.

## 'Agent 판단' 칸 점검

| 약한 판단 (목업이 되기 쉬움) | 강한 판단 |
| --- | --- |
| 뉴스를 보여 준다 | 내 분야 기준으로 3개를 고르고 고른 이유를 쓴다 |
| 회의록을 요약한다 | 결정·미정·할 일을 구분하고 없는 담당은 '미정'으로 둔다 |
| 노트북을 추천한다 | 조건 밖 후보를 이유와 함께 빼고, 남은 것 중 용도에 맞는 하나를 고른다 |
