## 2분 데모 구성

| 길이 | 보여줄 것 |
| --- | --- |
| 20초 | 어떤 문제를 풀었나 (관통 과제) |
| 60초 | 입력 → 결과를 실제로 돌려 보기 (테스트 입력 두 개면 더 좋음) |
| 40초 | AI가 판단한 부분과 사람이 확인하는 부분 |

### 데모 대본 예 · 회의록 정리기

> **(20초)** 회의가 끝나면 할 일과 마감을 정리해서 돌리는 데 매번 20분씩 걸렸습니다. 그래서 회의록을 넣으면 할 일표를 만들어 주는 '회의록 정리기'를 만들었습니다.
>
> **(60초)** 경진대회 준비 회의록을 넣어 보겠습니다. … 결정 사항과 할 일이 담당 · 마감과 함께 표로 나왔고, 폼 담당자는 회의록에 없어서 '미정'으로 나왔습니다. 이번엔 연구실 미팅 회의록을 넣으면 … 담당자와 마감이 전부 바뀌고, GPU 사용 기간은 바뀐 뒤의 '5일'로 정리됐습니다.
>
> **(40초)** AI가 판단하는 건 '무엇이 결정이고 무엇이 미정인가'입니다. 메일은 초안까지만 만들고, 보내는 건 제가 확인하고 직접 합니다. 회의록 안에 이상한 지시가 있어도 따르지 않게 해 두었습니다.

### 데모 대본 틀

```
(20초) [누가] [무슨 일]을 할 때 [어떤 불편]이 있어서, [입력]을 넣으면 [결과]를 주는 [에이전트 이름]을 만들었습니다.
(60초) [테스트 입력 ①]을 넣으면 … [테스트 입력 ②]를 넣으면 … 이렇게 달라집니다.
(40초) AI가 판단하는 건 [Agent 판단]이고, [사람 확인 지점]은 제가 직접 합니다.
```

## 제출

**제출 링크: https://forms.gle/KGyzhKQfjk4JJQfs8** — Ctrl+클릭(맥은 ⌘+클릭)으로 새 탭에서 엽니다.

| Form 문항 | 무엇을 넣나 | 트랙 A0은 이렇게 |
| --- | --- | --- |
| 1 · 데모 링크 또는 동작 결과 | 에이전트가 실제로 낸 결과 | 링크가 없어도 됩니다. 테스트 입력 ①에 대한 **AI 답 아래의 복사 아이콘**을 눌러 붙여 넣기 (앞부분만 넣어도 됨) |
| 2 · 설계 캔버스 5칸 | 메모장에 둔 내 캔버스 | 0단계에서 메모장에 붙여 둔 캔버스(5단계에서 한 칸 고친 것)를 복사해 붙여 넣기 |
