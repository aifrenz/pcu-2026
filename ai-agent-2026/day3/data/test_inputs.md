## 가상 노트북 6종

```
[후보 목록] (모두 가상 제품)
1. 가벼움 13 — 99만 원 / 0.99kg / 배터리 18시간 / 메모리 16GB / 13.3인치 FHD
2. 올라운드 14 — 129만 원 / 1.25kg / 배터리 14시간 / 메모리 16GB / 14인치 2.8K
3. 크리에이터 16 — 179만 원 / 1.95kg / 배터리 8시간 / 메모리 32GB / 16인치 OLED 4K, 색 정확도 높음
4. 게이밍 15 — 165만 원 / 2.3kg / 배터리 5시간 / 메모리 32GB / 15.6인치 165Hz, 외장 그래픽
5. 학생용 15 — 79만 원 / 1.6kg / 배터리 9시간 / 메모리 8GB / 15.6인치 FHD
6. 프로 14 — 219만 원 / 1.4kg / 배터리 20시간 / 메모리 32GB / 14인치 고해상도
```

| 테스트 | 조건 | 잘 된 결과라면 |
| --- | --- | --- |
| ① | 120만 원 이하 · 1.3kg 이하 · 문서·강의 수강 · 배터리 중시 | 1번 추천. 2번(예산 초과)·5번(무게 초과)·3·4·6번 제외 이유가 정확함 |
| ② | 180만 원 이하 · 무게 무관 · 영상 편집 · 화면 중시 | 3번 추천, 4번이 2순위. 6번은 예산 초과로 제외 |

## 가상 논문 초록 3편

```
[초록 1] 검색 근거 대조를 이용한 한국어 질의응답 답변의 환각 문장 탐지 (가상, 2026)
한국어 질의응답에서 대형 언어모델이 만든 답변 문장을 검색으로 찾은 근거 문서와 하나씩 대조해, 근거가 없는 문장을 환각으로 표시하는 방법을 제안한다. 한국어 뉴스 기반 질의응답 데이터 3천 건으로 평가했으며, 근거 문서가 짧을 때 탐지 성능이 떨어지는 한계가 있다.

[초록 2] 소량의 정상 데이터로 학습하는 설비 진동 이상 탐지 (가상, 2025)
공장 설비의 진동 센서 시계열에서 정상 구간 데이터만으로 자기지도 학습을 해 이상 징후를 찾는 방법을 제안한다. 세 개 공장의 회전 설비 데이터로 평가했으며, 설비 종류가 바뀌면 다시 학습해야 하는 한계가 있다.

[초록 3] 설비 로그를 읽고 이상 원인을 설명하는 LLM 에이전트 (가상, 2026)
설비 경보 로그와 정비 기록을 대형 언어모델 에이전트가 검색·요약해 이상 원인 후보를 설명하는 시스템을 제안한다. 에이전트가 근거 없이 원인을 단정하는 사례가 있어, 정비 기록과 대조하는 검증 단계를 추가했다.
```

| 테스트 | 내 연구 주제 | 잘 된 결과라면 |
| --- | --- | --- |
| ① | 한국어 LLM 답변의 환각 탐지 | 초록 1 '상', 초록 3 '중'(근거 없는 단정을 검증), 초록 2 '하' |
| ② | 제조 설비 센서 데이터 이상 탐지 | 초록 2 '상', 초록 3 '중'(설비 이상이지만 센서가 아닌 로그), 초록 1 '하' |

초록 3을 두 주제 모두에서 '중'으로 두고 이유를 다르게 쓰면 판단을 잘한 것입니다.

## 내 자료로 테스트하고 싶다면

- 공개된 자료만 씁니다. 회의록·메일은 이름을 `담당자A`, 기관명을 `○○기관`으로 바꾸고 금액·연락처를 지웁니다.
- 입력 두 개는 **결과가 달라져야 마땅할 만큼** 다르게 고릅니다.
