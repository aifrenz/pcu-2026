# 가상 회의록·메일 더 보기 (과제 B 실습용)

[`meeting_notes_sample.md`](meeting_notes_sample.md)의 경진대회 회의록 말고 다른 상황으로 해 보고 싶을 때 씁니다. 내 처지와 가까운 것을 하나 골라 `[회의록 붙여넣기]` 자리에 **코드 블록 안의 내용을 통째로** 붙여 넣으세요.

모두 실제 인물·기관과 무관한 가상 자료입니다. 일부러 모호하거나 바뀐 내용을 넣어 두었습니다. AI가 없는 내용을 지어내는지, '미정'으로 남기는지 보세요.

| 자료 | 이런 분께 | 특징 |
| --- | --- | --- |
| ① 연구실 주간 미팅 | 대학원생 | 결정이 중간에 바뀐 항목, 원인을 '추정'한 항목 |
| ② 고객지원팀 회의 | 직장인 | '확정'과 '잠정'이 섞인 일정 |

## ① 연구실 주간 미팅 (대학원생용)

```
[회의록] 지능정보연구실 주간 미팅
일시: 10월 12일(월) 10:00–11:00   장소: 공학관 4층 세미나실
참석: 김지훈 교수, 서준호(박사과정), 윤아름(석사 2기), 강태민(석사 1기)

1. 논문 투고
- 서준호 논문은 11월 15일 마감 학회에 투고하기로 확정. 실험 결과 표 2개를 추가해야 함.
- 영문 교정은 외부 업체에 맡길지 교수님이 직접 보실지 정하지 못함.

2. 실험 진행
- 윤아름: 베이스라인 재현 정확도가 원 논문보다 3%p 낮음. 하이퍼파라미터 차이로 추정. 이번 주 안에 원인을 찾기로.
- 강태민: 데이터 전처리 코드를 정리해 연구실 저장소에 올리기로. (마감은 말하지 않음)

3. GPU 서버
- 예약이 자꾸 겹침. 예약표를 공유 문서로 만들자는 의견. 만들 사람은 정하지 않음.
- 처음에는 1인 최대 3일 연속 사용으로 하자고 했으나, 논문 마감을 앞둔 사람은 5일까지 허용하기로 바꿈.

4. 기타
- 11월 연구실 세미나 발표자는 윤아름에서 강태민으로 변경 (윤아름 실험 일정 때문).
- 다음 미팅: 10월 19일(월) 10:00
```

**확인 포인트**

| 구분 | 잘 된 결과라면 |
| --- | --- |
| 결정 사항 | 11/15 학회 투고 확정 · GPU 연속 사용 3일, 마감 앞둔 사람은 5일 · 11월 세미나 발표자 강태민 |
| 미결정 사항 | 영문 교정 방식 |
| 할 일 | 표 2개 추가 — 서준호, 투고 전 · 정확도 원인 찾기 — 윤아름, 이번 주 · 전처리 코드 정리 — 강태민, 마감 미정 · 예약표 만들기 — 담당 미정 |
| 함정 | 바뀌기 전 내용(3일 제한, 윤아름 발표)을 결정으로 쓰거나, '추정'한 원인을 사실처럼 쓰면 감점 |

## ② 고객지원팀 주간 회의 (직장인용)

```
[회의록] 고객지원팀 주간 회의 — 상담 챗봇 도입 검토
일시: 10월 8일(목) 14:00–15:00   장소: 화상 회의
참석: 오세진 팀장, 문지호(상담 운영), 배수아(데이터), 임도현(IT 지원), 한가을(교육)

1. 도입 범위
- 1차 도입은 배송·환불 문의 두 가지로 한정하기로 합의. 결제 오류 문의는 제외.
- 모든 챗봇 화면에 '상담원 연결' 버튼을 둔다.

2. 업체 선정
- A사와 B사를 비교함. B사가 더 저렴하지만 상담 데이터를 국내에 보관하는지 확인이 필요.
- 임도현이 두 업체에 보안 질의서를 보내기로. 회신은 "다음 회의 전"까지 받기로.

3. 데이터 준비
- 배수아: 최근 6개월 상담 기록 중 배송·환불 문의를 골라 개인정보를 지운 뒤 공유. 일정은 다음 회의 때 알려 주기로.

4. 교육
- 상담원 대상 챗봇 운영 교육이 필요. 담당은 한가을. 교육 일정은 업체가 정해진 뒤에.

5. 기타
- 오픈 목표는 12월 첫째 주로 잠정. 업체 선정 뒤 확정.
- 다음 회의: 10월 15일(목) 14:00
```

**확인 포인트**

| 구분 | 잘 된 결과라면 |
| --- | --- |
| 결정 사항 | 1차 범위는 배송·환불 · 결제 오류 제외 · 모든 화면에 상담원 연결 버튼 |
| 미결정 사항 | 업체(A사/B사) · 오픈일(12월 첫째 주는 '잠정') · 교육 일정 |
| 할 일 | 보안 질의서 발송·회신 — 임도현, 10/15 회의 전 · 상담 기록 정리 — 배수아, 일정 미정(다음 회의 때 공유) · 운영 교육 — 한가을, 업체 선정 뒤 |
| 함정 | '잠정'을 확정으로 쓰거나, 저렴하다는 이유로 B사가 선정된 것처럼 쓰면 감점 |

## ③ 교육 일정 조율 메일 4통 (행정·교육 담당용)

회의록 대신 **오가는 메일**로 해 보는 버전입니다. 프롬프트의 '회의록'을 '메일 스레드'로, '참석자'를 '인사팀과 강사'로 바꿔 쓰세요.

```
[메일 스레드] 제목: RE: RE: RE: 11월 신입사원 생성형 AI 교육 문의

(1) 10월 5일 / 보낸 사람: 정다은(인사팀) / 받는 사람: 류민석 강사
강사님, 11월 신입사원 대상 생성형 AI 교육(4시간)을 부탁드리고 싶습니다.
가능한 날짜는 11월 12일(목) 또는 11월 19일(목) 오후입니다. 인원은 30명 안팎입니다.
수강생이 노트북을 가져와야 하는지도 알려 주세요.

(2) 10월 6일 / 보낸 사람: 류민석 / 받는 사람: 정다은
11월 19일은 가능하고 12일은 어렵습니다.
실습이 있어 노트북은 꼭 필요하고, 수강생 AI 계정을 미리 만들어 두셔야 합니다.
강의료 견적은 따로 메일 드리겠습니다.

(3) 10월 7일 / 보낸 사람: 정다은 / 받는 사람: 류민석
그럼 11월 19일로 진행하고 싶습니다.
장소는 본사 3층 대회의실로 생각하고 있는데 아직 확정은 아닙니다.
계정 만드는 방법 안내문은 어느 쪽에서 준비하면 될까요?

(4) 10월 8일 / 보낸 사람: 류민석 / 받는 사람: 정다은
안내문 초안은 제가 10월 20일까지 드리겠습니다.
견적은 첨부한 파일을 확인해 주세요.
```

**확인 포인트**

| 구분 | 잘 된 결과라면 |
| --- | --- |
| 정해진 것 | 11/19(목) 오후 · 4시간 · 노트북 필수 · 수강생 AI 계정 사전 생성 필요 |
| 정해지지 않은 것 | 장소(대회의실은 '예정') · 정확한 인원(30명 안팎) · 강의료 |
| 할 일 | 계정 안내문 초안 — 류민석, 10/20 · 장소 확정 — 정다은, 기한 미정 · 수강생 계정 생성 — 인사팀(담당자 미정) |
| 함정 | (4)에서 '첨부했다'는 견적 파일이 실제로는 없습니다. 견적 금액을 지어내지 않고 "첨부 없음, 다시 요청 필요"로 짚으면 아주 잘한 것 |
