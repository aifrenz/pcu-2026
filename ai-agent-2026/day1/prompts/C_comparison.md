# 과제 C · 조사 비교표

예제 조건: [`../data/comparison_personas.md`](../data/comparison_personas.md)에서 페르소나 하나를 골라 `[ ]`에 넣습니다. 노트북 대신 채용공고·논문·서비스 비교로 바꿔도 됩니다.

## STEP 1

```
대학생용 노트북 추천해 줘
```

## STEP 2 · 사람이 지휘한다

**① 조사**
```
지금 판매 중인 노트북 중 [예산 150만 원 이하, 1.5kg 이하] 후보를 6개 찾아 줘. 가격은 출처와 확인 날짜를 붙여 줘.
```

**② 분석**
```
[문서 작업·코딩·하루 8시간 이동] 용도에서 각각의 장단점을 뽑고, 조건에 맞지 않는 후보는 이유와 함께 빼 줘.
```

**③ 정리**
```
남은 3개를 표로 비교해 줘. 열: 제품 · 가격 · 무게 · 배터리 · 메모리 · 장점 · 단점 · 출처
```

**④ 작성**
```
표를 바탕으로 추천 1개와 그 이유, '이런 사람에게는 2순위가 낫다'를 한 문단으로 써 줘.
```

## STEP 3 · AI에게 맡긴다

```
목표: 내 조건에 맞는 노트북 3개를 비교하고 하나를 추천한다.
독자·용도: 나. 이번 달 안에 구매를 결정한다.
조건: 예산 [150만 원] 이하, [1.5kg] 이하, 용도는 [문서 작업·가벼운 코딩·하루 8시간 이동].
평가 기준:
1. 후보는 지금 실제로 판매 중이고, 가격·사양에 출처와 확인 날짜가 있다
2. 조건을 벗어난 후보는 빼고, 뺀 이유를 한 줄로 남긴다
3. 추천 이유가 내 용도와 연결된다
제약: 광고·협찬 리뷰는 근거로 쓰지 않는다. 확인 못 한 사양은 '확인 필요'.
산출물: 비교표(제품·가격·무게·배터리·메모리·장점·단점·출처) + 추천 한 문단 + 제외한 후보 목록

계획을 먼저 보여 주고 진행해 줘. 조건이 모호하면 나에게 먼저 물어봐.
```

## 관찰 포인트

- 페르소나를 바꿔 다시 보내면 추천이 바뀌나요? 바뀐다면 그것이 에이전트의 '판단'입니다.
- 가격 정보에 날짜가 붙어 있나요? 가격은 매일 바뀝니다.
