# 과제 D · 내 업무

예시는 직장인 대학원생의 '논문 동향 정리'입니다. 직장인이라면 '논문'을 '경쟁사 보도자료', '관련 정책·공고'로 바꾸면 같은 틀로 쓸 수 있습니다.

`[내 연구 주제]`가 막막하면 [`../data/fill_in_examples.md`](../data/fill_in_examples.md#과제-d--내-업무--내-연구-주제)에서 분야별 예시 13개 중 하나를 고르세요. 바로 붙여 넣는 완성본(대학원생·직장인용)도 있습니다.

## STEP 1

```
[내 연구 주제] 최근 논문 알려줘
```

## STEP 2 · 사람이 지휘한다

**① 조사**
```
[내 연구 주제]에 대한 최근 2년 논문을 8편 찾아 줘. 제목 · 저자 · 연도 · 링크를 붙이고, 링크로 확인할 수 없는 논문은 빼 줘.
```

**② 분석**
```
각 논문의 문제 · 방법 · 데이터 · 한계를 한 줄씩 뽑아 줘.
```

**③ 정리**
```
관련성이 높은 5편을 비교표로 만들고, 공통으로 나타나는 한계를 묶어 줘.
```

**④ 작성**
```
지도교수님께 보낼 1쪽 메모를 써 줘. 연구 동향 3줄, 비교표, 내가 파고들 수 있는 연구 공백 2가지.
```

## STEP 3 · AI에게 맡긴다

```
목표: [내 연구 주제]의 최근 2년 논문 5편을 정리하고 연구 공백 2가지를 제안한다.
독자·용도: 지도교수님께 드릴 주간 미팅 메모.
평가 기준:
1. 모든 논문은 링크로 실제 존재를 확인할 수 있다 (없는 논문 금지)
2. 논문마다 문제·방법·데이터·한계가 정리돼 있다
3. 연구 공백은 논문들의 공통 한계에서 나온다
제약: 동료심사 논문과 arXiv 위주. 확인 못 한 내용은 '확인 필요'. 1쪽.
산출물: 동향 3줄 + 비교표(논문·연도·문제·방법·데이터·한계·링크) + 연구 공백 2가지

계획을 먼저 보여 주고 진행해 줘. 판단이 필요하면 나에게 물어봐.
```

## 내 업무로 바꿀 때 체크

- [ ] 개인정보·기밀이 없는 공개 자료로 할 수 있는 일인가?
- [ ] '좋은 결과'를 확인할 수 있는 기준 3가지를 쓸 수 있는가?
- [ ] 결과를 받아 볼 사람(독자)이 분명한가?

셋 중 하나라도 '아니오'면 A·B·C 중 하나로 바꾸는 것이 실습에 더 좋습니다.
