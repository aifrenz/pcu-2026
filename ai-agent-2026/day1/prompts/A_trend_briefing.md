# 과제 A · 동향 브리핑

'AI 에이전트' 대신 내 관심 주제로 바꿔도 됩니다. 처지별 주제·독자 예시와 바로 붙여 넣는 완성본은 [`../data/fill_in_examples.md`](../data/fill_in_examples.md#과제-a--동향-브리핑--주제와-독자-바꾸기)에 있습니다.

## STEP 1

```
이번 주 AI 에이전트 관련 소식 알려줘
```

## STEP 2 · 사람이 지휘한다 (한 대화창에서 차례로)

단계마다 결과를 읽고, 필요하면 고쳐 달라고 한 뒤 다음으로 넘어갑니다. 고친 횟수를 세어 두세요.

**① 조사**
```
최근 7일 동안 나온 'AI 에이전트' 관련 주요 소식을 10개 찾아 줘. 각 소식마다 날짜, 출처 링크, 한 줄 요약을 붙여 줘. 공식 발표와 주요 언론 위주로.
```

**② 분석**
```
찾은 10개를 '제품 출시 / 기업·투자 / 규제·정책 / 연구' 네 갈래로 나누고, 이번 주 흐름을 3문장으로 정리해 줘. 서로 연결되는 소식이 있으면 짚어 줘.
```

**③ 정리**
```
중요도 순으로 상위 5개를 골라 표로 만들어 줘. 열: 날짜 · 소식 · 분류 · 왜 중요한가(1줄) · 출처
```

**④ 작성**
```
이 표를 바탕으로 [우리 팀 동료]에게 보낼 주간 브리핑을 써 줘. 제목, 3줄 요약, 표, '우리에게 주는 시사점' 2개. 1쪽 이내.
```

## STEP 3 · AI에게 맡긴다 (새 대화에서 한 번에)

검색·리서치 기능이 있으면 켭니다. 아래를 **한 번에** 보내고, AI가 묻는 것에만 답합니다.

```
목표: 최근 7일 동안의 AI 에이전트 분야 핵심 소식 5개로 주간 브리핑을 만든다.
독자·용도: AI에 관심 있는 [우리 팀 동료]. 월요일 아침 3분 안에 읽는다.
평가 기준:
1. 모두 최근 7일 이내 소식이고, 날짜와 원문 링크가 있다
2. 같은 소식을 중복하지 않고, 분야가 한쪽에 몰리지 않는다
3. 소식마다 '왜 중요한가'가 한 줄씩 있다
제약: 공식 발표·주요 언론 우선. 확인되지 않은 내용은 '추정'으로 표시. 1쪽 이내, 한국어.
산출물: 제목 + 3줄 요약 + 표(날짜·소식·분류·왜 중요한가·출처) + 시사점 2개

계획을 먼저 보여 주고 진행해 줘. 판단이 필요하면 나에게 물어봐.
```

## 관찰 포인트

- AI가 세운 계획은 내 STEP 2의 4단계와 같았나요, 달랐나요?
- 검색을 몇 번 했나요? 결과를 보고 검색어를 바꿨나요? (Observe → Re-plan)
- 7일보다 오래된 소식을 걸러냈나요?
