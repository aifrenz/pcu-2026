## STEP 1

```
이 회의록 요약해 줘
[회의록 붙여넣기]
```

## STEP 2 · 사람이 지휘한다

**① 파악**
```
아래 회의록을 읽고 ① 결정된 사항 ② 논의만 하고 결정 못 한 사항 ③ 할 일을 구분해서 뽑아 줘.
[회의록 붙여넣기]
```

**② 분석**
```
할 일마다 담당자와 마감일을 찾아 줘. 회의록에 없는 정보는 '미정'으로 두고 추측하지 마.
```

**③ 정리**
```
할 일을 표로 만들어 줘. 열: 번호 · 할 일 · 담당 · 마감 · 상태(확정/미정)
```

**④ 작성**
```
참석자에게 보낼 회의 결과 공유 메일 초안을 써 줘. 결정 사항 3줄, 할 일 표, 다음 회의 전에 확인할 미정 사항.
```

## STEP 3 · AI에게 맡긴다

```
목표: 아래 회의록을 참석자가 바로 움직일 수 있는 '회의 결과 공유 메일'로 만든다.
독자·용도: 회의 참석자 5명. 메일을 읽고 자기 할 일과 마감을 바로 알아야 한다.
평가 기준:
1. 결정 사항과 미결정 사항이 섞이지 않는다
2. 모든 할 일에 담당·마감이 있고, 회의록에 없으면 '미정'으로 표시한다
3. 회의록에 없는 내용을 만들어 넣지 않는다
제약: 메일 본문 한 화면 이내, 존댓말.
산출물: 메일 제목 + 결정 사항 3줄 + 할 일 표(번호·할 일·담당·마감·상태) + 미정 사항 목록

계획을 먼저 보여 주고 진행해 줘. 판단이 필요하면 나에게 물어봐.

[회의록 붙여넣기]
```
