# 좋은 위임 프롬프트 만들기

**위임 = 목표 + 독자 + 평가 기준 + 제약 + 산출물 + 일하는 방식.**
길게 쓰는 것이 아니라, AI가 스스로 판단할 수 있는 재료를 주는 것입니다.

## 약한 지시 → 강한 지시

| 약한 지시 | 무엇이 빠졌나 | 강한 지시 |
| --- | --- | --- |
| AI 뉴스 정리해 줘 | 기간, 독자, 고르는 기준 | 최근 7일 AI 에이전트 소식 중 [내 분야] 실무자에게 중요한 5개를, 날짜·링크·중요한 이유와 함께 표로 |
| 회의록 요약해 줘 | 누가 읽고 무엇을 하는지 | 참석자가 자기 할 일과 마감을 바로 알 수 있게. 회의록에 없는 담당·마감은 '미정' |
| 좋은 노트북 추천해 줘 | '좋은'의 기준 | 150만 원 이하 · 1.5kg 이하 · 하루 8시간 이동. 조건 밖 후보는 이유와 함께 제외 |
| 보고서 잘 써 줘 | '잘'을 확인할 방법 | 1쪽, 표 먼저, 수치마다 출처, 결론은 첫 문단에 |

## 평가 기준 쓰는 법

1. **확인할 수 있게** 씁니다. '자세히'는 확인이 안 되고, '소식마다 링크 1개 이상'은 확인됩니다.
2. **숫자를 넣습니다.** 기간(7일), 개수(5개), 분량(1쪽).
3. **하지 말 것을 씁니다.** '추측하지 마', '광고 리뷰는 근거로 쓰지 마'.
4. **기준은 3개 안팎**이 좋습니다. 너무 많으면 우선순위가 흐려집니다.

## 한 줄로 결과를 바꾸는 문장

| 문장 | 효과 |
| --- | --- |
| `계획을 먼저 보여 주고 진행해 줘` | AI가 단계를 스스로 나누고, 사람은 방향만 확인 |
| `시작 전에 나에게 필요한 질문을 3개까지 먼저 해 줘` | 빠진 조건을 AI가 찾아 질문 |
| `판단이 필요하면 나에게 물어봐` | Human-in-the-loop 지점을 AI에게 맡김 |
| `끝에 기준 3가지를 스스로 점검한 표를 붙여 줘` | AI가 결과를 다시 보고 고침 (Observe → Re-plan) |
| `확인하지 못한 내용은 '확인 필요'로 표시해 줘` | 지어낸 내용을 줄이고 사람이 검증할 곳을 표시 |

## 한 장 프롬프트 카드

모니터 옆에 두고 쓰세요.

```
[위임 틀]
목표: 무엇을 끝내야 하나
독자·용도: 누가, 어디에 쓰나
평가 기준: 확인할 수 있는 조건 3가지 (숫자·기간·출처)
제약: 하지 말 것, 분량, 출처 수준
산출물: 형식 (표 · 1쪽 · 메일 등)

[결과를 바꾸는 문장]
계획을 먼저 보여 주고 진행해 줘.
시작 전에 필요한 질문을 3개까지 먼저 해 줘.
판단이 필요하면 나에게 물어봐.
확인하지 못한 내용은 '확인 필요'로 표시해 줘.
끝에 기준 3가지를 스스로 점검한 표를 붙여 줘.
```
