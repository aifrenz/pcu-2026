## 기본 트랙과 심화 트랙

- **기본 트랙**은 웹 브라우저와 AI 서비스 계정(무료 가능)만으로 3일 모두 완주할 수 있습니다. 코드는 필요 없습니다.
- **심화 트랙**은 개발 경험자를 위한 선택 과제입니다. DAY 1 · 2는 `advanced/`, DAY 3은 `tracks/`(트랙 A · B · C)와 `demo/`(강의 시연), `examples/`(완성 예시)에 있습니다.

## 안전 수칙

1. 개인정보·회사 기밀은 AI에 입력하지 않습니다. 실습은 공개 자료나 이 저장소의 가상 예제로 합니다.

심화 트랙(코드)을 하는 분은 다음도 지킵니다.

2. **API 키는 비밀번호입니다.** 코드·스크린샷·제출물에 넣지 말고, `.env` 파일이나 환경 변수에만 둡니다. `.env`는 `.gitignore`로 저장소에 올라가지 않게 막혀 있습니다.
3. API 키를 쓴다면 서비스 콘솔에서 **지출 상한**을 먼저 설정하고, 실습 뒤에는 키를 폐기하거나 한도를 낮춥니다.
